<h1 align="center">SneakGrow</h1>

<h3 align="center"><em>スニークすることで、苗木や作物、動物の成長を促進できます</em></h3>

## 特徴

苗木や作物、動物の周りで踊るだけで、簡単に成長を促進できるプラグインです！  
近くでしゃがむと成長が早まり、しゃがめばしゃがむほど育ちます。

子どもの動物は早く成長し、繁殖後の動物は再び繁殖できるようになるまでの時間が短くなります。

## 使い方

### Shift キーを連打しよう！

## 詳細

このプラグインは、苗木や作物、動物の近くでプレイヤーがしゃがんだことを検知し、作物を成長させます。  
反応のしやすさは設定ファイルで変更できます。

成長が促進されるたびに骨粉のパーティクルが表示されます。この演出も設定ファイルで無効にできます。
